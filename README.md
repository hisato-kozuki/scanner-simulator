# Scanner Simulator

立体物をスキャナーで読み込み3Dデータを作成するツールの練習を行うためのスマホ向けWebアプリである．スマホ画面に3DモデルをAR表示し，アプリから指示された方向にスマホを向けてスキャンを行うことでクリアできる．
詳しい狙いは `CLAUDE.md` を参照。

## ファイル構成

- `index.html` / `css/style.css` / `js/*.js`: 実装（サーバー処理なし）
- `js/vendor/`: Three.js r160（同梱）
- `image/logo.png`: 空中に投影する画像（未配置の場合は代替画像を表示）
- `CLAUDE.md`: Claude Code向けの開発方針・完成条件

## 動かし方

ビルド不要の静的サイトなので、このフォルダを任意の静的サーバーで配信するだけで動く。

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

ES Modulesと画像の読み込みを使うため、`file://`で直接`index.html`を開いても動作しない。
PCなど傾きセンサーがない環境では、画面のドラッグで方位と仰角を操作できる。

## スマホでの確認

カメラと傾きセンサーはHTTPS接続でないと利用できない。GitHub PagesなどのHTTPSで配信されたURLをスマホで開くこと。
同じLANのPCへ`http://`で接続した場合は、カメラと傾きセンサーのどちらも動作しない。

## 操作

1. 「開始」をタップし、カメラとセンサーの利用を許可する。
2. 方位0度（北）、仰角45度（水平より45度下）にスマホの背面を向ける。目標に近づくほど画像が不透明になる。
3. 目標から10度以内で画像が不透明になっている間にスキャンボタンを長押しする。合計5秒で完了する。それ以外の向きで押すと「Error」と表示される。
